FoldLog는 개인정보를 존중합니다. 접기와 펼치기 기록 및 일일 목표는 기기에서 처리·저장되며 개발자에게 자동 전송되지 않습니다. 기록은 직접 확인, 내보내기, 삭제할 수 있습니다.

01 적용 범위와 연락처

이 방침은 FoldLog iOS 앱, 함께 제공되는 위젯, 지원 웹사이트에 적용됩니다. “개발자”는 FoldLog 개인 개발자를 의미합니다. 방침, 데이터 처리, 권리에 관한 문의는 chenwxiong@gmail.com으로 보내주세요.

앱의 기기 내 데이터, 직접 보내는 지원 이메일, 웹사이트 방문은 아래에서 구분하여 설명합니다.

02 기기에서 처리하는 데이터

다음 데이터는 동작 기록, 목표, 기록 조회, 위젯을 제공하기 위해 사용하며 기본적으로 기기에 저장합니다.

분류데이터목적
동작 이벤트와 기록닫힘·반쯤 펼침·완전히 펼침 유형, 시각, 임의 이벤트 식별자, 기록 파일 생성일, 통계 시간대통계일별 오늘·누적·과거 횟수 계산
일일 목표세 수치의 상한, 활성 상태, 적용일, 임의 목표 식별자목표·남은 횟수·적용 규칙 표시
환경설정외관 설정표시 선택 유지
호환성과 실시간 상태모델 식별자, 시스템 버전, 기기 종류, 시스템이 제공하는 힌지 상태, 짧은 구간 측정용 단조 시계기기 내 호환성 확인, 상태 변화 인식, 연속 1초의 반쯤 펼침 확인
위젯 요약통계일·시간대, 오늘의 접기, 접기 목표, 갱신 시각, 필요한 기록 상태 표시같은 기기의 위젯에 오늘의 접기와 남은 횟수 표시

임의 식별자는 기기 내 항목을 구별합니다. 광고 식별자가 아니며 실제 신원을 식별하거나 추적하는 데 쓰지 않습니다. 모델 식별자는 기종을 나타내며 일련번호가 아닙니다.

실시간 힌지 상태와 시간 정보는 관측 및 계산에 사용합니다. 원시 힌지 각도 시퀀스나 단조 시계의 원시 값은 내보내는 기록에 저장하지 않습니다. 실제 수신하고 저장한 유효한 동작만 기록하며 가능한 경우 백그라운드 콜백도 기록합니다. 시스템 중단이나 입력 누락으로 공백이 생길 수 있어 하루 전체의 활동을 재구성할 수 없습니다.

03 저장과 사용

기록 파일은 앱의 로컬 저장 공간에, 환경설정은 시스템의 앱 설정 저장소에 보관합니다.

위젯은 같은 기기에서 시스템이 관리하는 공유 저장소의 요약을 읽습니다. 개발자 서버에 데이터를 요청하거나 동작을 독립적으로 수집하지 않습니다. 요약은 전체 이벤트 기록이 아닙니다.

화면을 볼 수 있는 사람은 홈 화면이나 잠금 화면의 위젯도 볼 수 있습니다. 시스템 위젯 설정에서 제거하거나 제공되는 잠금 화면 옵션을 조정할 수 있습니다.

현재 개발자 운영 계정, 클라우드 동기화, 광고, 타사 분석 SDK는 없습니다. 기기 내 기록을 자동 수신하지 않으며 앱·사이트 간 광고 추적이나 개인정보 판매를 하지 않습니다.

04 권한과 플랫폼 서비스

위치, 연락처, 사진, 카메라, 마이크 권한을 요청하지 않습니다. 힌지 상태, 호환성 확인, 위젯에는 시스템 기능을 사용합니다.

App Store 다운로드·업데이트 또는 TestFlight 사용 시 Apple은 사용자의 설정과 정책에 따라 구매, 배포, 충돌 진단, 테스트 정보를 처리할 수 있습니다. 해당 서비스에서 직접 제출한 피드백 및 Apple이 개발자에게 제공하는 진단·집계 정보는 문제 해결과 유지 관리에 사용될 수 있습니다. 범위는 Apple의 서비스, 설정, 정책에 따르며 앱에 타사 분석 SDK가 있다는 뜻은 아닙니다.

Apple 개인정보 처리방침을 확인하세요.

05 내보내기와 공유

설정 → 데이터에서 JSON을 내보낼 수 있습니다. 이벤트 유형·시각, 임의 식별자, 목표·적용일, 기록 파일 생성일, 통계 시간대가 포함될 수 있습니다.

직접 내보내기를 시작하고 시스템 공유 화면에서 위치, 앱, 수신자를 선택합니다. 선택한 클라우드 드라이브, 이메일 등은 해당 서비스의 규칙으로 파일을 처리합니다. 공유 전 내용과 수신자를 확인하세요.

현재 JSON 가져오기를 통한 복원은 지원하지 않습니다. 내보내기는 사본 보관·확인용이며 복원을 보장하지 않습니다. 앱에서 지워도 공유한 사본은 회수되지 않습니다.

06 보관 기간, 삭제, 시스템 백업

로컬 기록은 직접 지우거나 관련 앱 데이터를 제거할 때까지 보관되며, 앱 삭제나 기기 고장 등으로 사라질 수 있습니다. 7일·30일 기록 필터는 표시 범위이며 이전 기록을 자동 삭제하지 않습니다.

  • 설정 → 데이터의 삭제를 확인하면 확인 창의 범위에 따라 횟수, 기록, 목표를 초기화하고 위젯 요약을 갱신합니다. 앱에서 취소할 수 없습니다.
  • 기록 지우기는 외관 등 모든 환경설정이나 내보내고 공유한 사본을 함께 삭제하지 않습니다.
  • 위젯 제거는 표시 항목을 없애며 앱의 기록을 지우지 않습니다.
  • 시스템의 앱 삭제는 보통 로컬 데이터도 제거합니다. 앱 정리하기는 문서와 데이터를 남길 수 있습니다. 공유 컨테이너나 백업 복원은 다르게 처리될 수 있으므로 실제 시스템 안내를 따르세요.

파일이 iCloud 기기 백업, 컴퓨터 백업, 기기 이전에 포함되는지는 시스템과 설정에 따릅니다. 개발자 클라우드 동기화가 없다고 해서 사용자가 켠 시스템 백업에서 제외된다는 보장은 없습니다. 백업과 내보낸 사본은 각각의 위치에서 관리하세요.

개발자는 로컬 기록의 원격 사본이 없으며 원격으로 읽거나 삭제·복원할 수 없습니다.

07 지원 문의

chenwxiong@gmail.com으로 문의하면 이메일 주소, 메시지, 직접 첨부한 스크린샷·진단 정보·파일을 받습니다. 답변, 문제 조사, 권리 요청 처리, 필요한 연락 기록에만 사용하며 광고 프로필에는 쓰지 않습니다.

앱·시스템 버전, 기종, 재현 단계를 먼저 알려주세요. 무관한 개인정보는 가리고 전체 기록, 비밀번호, 민감한 자료는 보낼 필요가 없습니다. 앱의 문의 기능은 기록을 자동 첨부하지 않습니다.

Gmail 등의 메일 서비스가 전송과 보관에 관여하며 다른 국가·지역에서 처리될 수 있습니다. 요청 처리, 필요한 연락 기록, 법적 의무에 필요한 기간만 보관하고 이후 삭제 또는 익명화합니다. 같은 이메일로 삭제를 요청할 수 있습니다. 메일 사업자는 자체 방침도 적용합니다. Google 개인정보처리방침을 참고하세요.

08 웹사이트 방문과 외부 링크

이 공개 사이트는 GitHub Pages 호스팅을 기준으로 준비되었습니다. 배포된 페이지 방문 시 GitHub는 보안·서비스 운영을 위해 IP 주소 등 접속 기록을 처리할 수 있으며 서비스를 제공하는 국가·지역에서 처리할 수 있습니다. GitHub 개인정보 처리방침을 확인하세요.

광고, 방문 분석 스크립트, 타사 글꼴, 소셜 추적 구성요소가 없습니다. 광고·분석 쿠키를 의도적으로 설정하지 않으며 기기의 FoldLog 기록을 읽지 않습니다. 기록 업로드 화면도 없습니다.

외부 사이트나 메일 링크를 이용하면 해당 서비스의 규칙이 적용됩니다. 지원 사이트를 방문한다고 앱 기록이 호스팅 업체로 전송되지는 않습니다. 앱에 포함된 방침은 오프라인으로 읽을 수 있습니다.

09 선택과 권리

기록 조회, 목표 변경·해제, 내보내기, 삭제, 사용 중단, 시스템을 통한 앱 삭제가 가능합니다. 탈퇴할 계정은 없습니다.

관련 법률에 따른 열람, 정정, 삭제, 처리 제한, 동의 철회, 민원 등의 권리는 개발자가 실제 보유한 정보에 대해 이메일로 요청할 수 있습니다. 필요한 범위에서만 확인하고 관련 법률에 따라 처리합니다. 전체 로컬 기록을 보낼 필요는 없습니다. 기기에만 있는 데이터는 로컬 관리 기능을 사용하세요.

10 미성년자

개인의 기기 사용 습관을 돕는 앱으로 어린이 전용이 아니며 나이나 생년월일을 요구하지 않습니다. 미성년자는 보호자 지도하에 사용하고 지역 법률에서 요구하는 동의를 받아야 합니다.

지원 이메일 등에 개발자가 보유해서는 안 되는 미성년자 정보가 있다고 생각되면 연락해 주세요. 확인하고 처리하겠습니다.

11 보안과 업데이트

로컬 파일은 iOS 저장소 격리와 시스템 보안에 의존하며 수신한 지원 정보는 합리적인 조치로 보호합니다. 기기 접근, 시스템 계정, 내보낸 파일도 보호하세요. 어떤 저장·전송 방법도 절대적 안전을 보장할 수 없습니다.

방침이 바뀌면 새 버전과 날짜를 표시합니다. 향후 계정, 동기화, 분석, 유료 기능 등으로 데이터 처리가 바뀌면 방침을 갱신하고 법률이 요구하는 추가 안내와 동의 절차를 진행합니다.
