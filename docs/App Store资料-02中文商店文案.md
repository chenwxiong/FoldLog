# App Store 资料 02 · 中文商店文案

日期：2026-10-24。版本：v0.1。状态：草案已输出，待用户核对。

用户已认可“从折痕关注出发，通过开合记录与每日目标支持少玩手机等自我管理”的内容方向。名称暂沿用“折记 / FoldLog”，本轮不将具体名称、副标题或其他字段视为已最终确认。

本轮交付可复制的中文应用描述、搜索关键词和推广文本。文案基于当前实现整理，正式提交前应以 Duo 真机验证及发布构建为准。首发地区、价格、发布主体和英语本地化尚未决定。

## 一、应用描述

下方文本为建议粘贴到“描述”字段的完整草案；框外说明不属于商店正文。

```text
在意折叠屏的折痕，也想少一点随手刷手机。

折记通过记录折叠与展开次数、设置每日目标，帮助你了解自己的开合习惯，尝试减少不必要的开合，把少玩一点手机的想法变成可以回顾的日常行动。

仅支持 iPhone Duo，需 iOS 27.1 或更新版本。当前仅记录 App 在前台时收到的有效开合事件；切换到其他 App、锁屏或退出后的开合不属于当前记录范围。

了解自己的开合习惯
分别查看折叠、半开与全开的今日次数和累计记录，了解已记录时段内的开合情况。

为自己设定每日目标
按自己的习惯，分别设置三类次数的每日上限。查看目标进度，给随手展开手机的习惯多一点思考的机会。目标由你决定，达到上限后仍会继续记录。

回顾变化，逐步调整
查看近 7 天或 30 天的历史图表，浏览每日次数与事件时间。结合自己的生活安排，回顾目标和记录，尝试找到更适合自己的手机使用节奏。

无需账号，本地保存
开合记录与目标保存在本机，无需注册账号。支持将当前模式的记录导出为 JSON 文件，也可清空当前模式的数据。当前尚不支持导入恢复。

计数与使用说明
• 折叠、半开、全开分别统计。从合拢进入半开并连续停留满 1 秒，才计入一次半开；短暂经过不计。
• 半开后再全开可能分别计数，两者之和不等于打开手机的总次数。
• 演示记录与设备记录分别保存，演示操作不会修改设备记录。
• 次数用于回顾已记录的开合行为，不代表屏幕使用时长。每日目标支持自主调整习惯，不会限制其他 App 的使用。
• 次数不能判断折痕程度、屏幕健康或剩余寿命，也不能保证减少折痕。

爱护折叠屏，也把更多注意力留给生活。
```

## 二、搜索关键词

```text
折叠屏,展开,半开,全开,计数,每日目标,自律,少玩手机,使用习惯,历史统计
```

选择依据：覆盖折叠屏与具体姿态、次数与每日目标，以及自律、少玩手机和习惯回顾。未重复暂定商店名中的完整词组；未加入未实现的番茄钟、屏幕时长测量、应用锁、折痕检测或寿命预测等功能词。

关键词未做搜索量、竞争度或排名验证，本轮只确认含义与产品相符。用英文半角逗号分隔，不加逗号后的空格。

## 三、推广文本

```text
在意折痕，也想少一点随手刷手机。通过开合记录、每日目标与历史回顾，了解自己的使用习惯，尝试减少不必要的开合。仅支持 iPhone Duo，需 iOS 27.1+；当前仅记录 App 前台的有效开合。
```

这是可选字段的建议稿。没有加入价格、首发日期或量化的专注 / 折痕改善效果。

## 五、待核对内容

1. 开头是否准确表达“在意折痕，同时想少玩手机”的使用动机。
2. 每日目标、自主调整习惯的表述是否符合希望传达的语气。
3. 是否沿用目前明确的前台记录范围；如果实际发布功能发生变化，需要同步修改正文和推广文本。
4. 是否保留 JSON 导出与计数口径的说明。文案中的半开 / 全开是独立次数，不新增“展开总次数”。
5. 首发地区和是否另做英语资料，留待后续确认。

不根据本轮文案扩展 App 功能。屏幕使用时长测量、通知提醒、强制禁用、全天后台统计与折痕测量均未作为现有卖点。
