# 折记 / FoldLog · App Store 上架资料清单

整理日期：2026-10-24。用户已认可“折痕关注、目标与少玩手机等自我管理”的内容方向；第 1 轮名称与副标题暂沿用 v0.2 草案，第 2 轮中文商店文案已输出，具体字句继续核对。

本清单针对当前 iOS 原生项目。工作名称“折记 / FoldLog”尚未定稿；仅支持 iPhone Duo、发布版本要求 iOS 27.1+，沿用已确认的产品范围。

“已有”表示项目中存在可复用材料，不代表用户已确认或已满足提交要求。账号、商店名称可用性和后台配置尚未核验。

网页托管与内置方案（2026-10-24 补充）：

- 用户明确无法办理 ICP 备案。网页按 GitHub Pages 的默认 `github.io` 域名和境外托管方案准备，不要求购买域名或使用中国大陆服务器；该网站托管通常无需办理中国大陆的网站 ICP 备案。
- App 内可内置相同版本的隐私政策与帮助内容，方便离线阅读，并保留隐私政策网页版链接。内置内容不能替代 App Store Connect 要求填写的公开隐私政策网址和技术支持网址。
- 网站备案与 App 备案分别判断。若选择中国大陆商店发行，仍需按 App 实际服务方式核实适用要求；不能因采用 GitHub Pages 或目前是本地工具就直接承诺免 App 备案。
- GitHub Pages 在中国大陆的访问稳定性需要实测，不作为可用性保证。公开网站仅放必要的支持材料，避免把整个未公开 App 工程误设为公开。
- GitHub 官方说明访问 Pages 时会为安全目的记录访问者 IP。后续隐私政策应区分 App 内本地数据处理与外部支持网站托管方的访问日志。

隐私初步依据：当前源码未见网络上传、广告、分析 SDK 或账号系统，可先以“开发者不收集数据”为候选填写方向，再核对最终发布包和后台问法。政策应区分“App 不向开发者服务器发送数据”与“用户主动分享、操作系统可能备份文件”，避免无依据地承诺数据绝不会进入任何云端。

工程配套项：当前使用了 `UserDefaults` / `@AppStorage`，项目尚未发现 `PrivacyInfo.xcprivacy`。提交前需核对 Apple 必须声明理由的 API 清单，为实际用途补齐隐私清单并检查归档报告。“App 隐私问卷”和工程隐私清单是两个独立事项。

当前无注册功能，无需专门准备账号注销流程；若以后加入账号、云同步、广告或付费，应同步重审本节。

## 七、正式提交前仍需解决的项目

资料可以先准备，以下事项需在提交前完成，不应在介绍中写成已验证成果：

- 验证真实 Duo 上的铰链计数、内外屏切换、前台有效范围与稳定性，并确定正式首版功能口径。
- 核实 App Store 如何筛选支持机型。当前只限制运行入口和 iPhone 设备族，不能证明其他 iPhone 无法下载；描述中写“仅 Duo”不能替代下载兼容配置。
- 将开发体验版整理为完整可用的正式版本；本地存储、权限和隐私声明与发布包一致。
- 补齐隐私政策入口、支持与隐私网页，完成隐私清单核对、正式签名及后台声明。
- 按最新后台要求确认截图尺寸、必填项、字段长度和地区条件，再上传最终素材。

每轮流程：输出草案 → 用户核对 → 修改 → 标记已确认。生成文件不自动视为已确认；后续已确认内容回写本清单。
